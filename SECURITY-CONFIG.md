# 凭据配置 / Credential configuration

两个 PhoenixSuit 安装包因 GitHub 潜在凭据告警而移除，有效性和归属尚未确认；请从厂商获取安装工具。

Bundled PhoenixSuit_CN.msi and PhoenixSuit_CN_debug.msi were removed because GitHub flagged potential credentials inside them. Their validity and ownership are unconfirmed. Obtain installation tools directly from the vendor.

已公开的真实凭据仍须撤销或更换。历史重写不能清除其他人的克隆、Fork 或 GitHub 缓存。

Revoke or rotate real credentials that were exposed. Rewriting history does not remove other clones, forks, or GitHub caches.
